## Financial research progress

The research progress treatment takes structural inspiration from [Progress bar by Ruslan for re:point](https://dribbble.com/shots/3407922-Progress-bar): connected isometric columns, filling milestones and small animated symbols. Beyond's illustration is original SVG with bank architecture, a financial filing and magnifier, an evidence-review shield, a report and a rupee coin. The palette stays green, sage and beige with a restrained brass accent.

Four clickable milestones group the eleven backend stages into Discover, Examine, Challenge and Report. Clicking a milestone only opens its explanation; **Follow live stage** restores automatic selection. Pillar height and the stage track are based on the reported workflow stage, not a timer or an invented completion percentage. Source, document, calculation and challenge counts come directly from the run summary. Queued runs remain waiting; interrupted runs retain the last known stage from the event log and stop ambient motion. Completion hands over to the existing report, including honest abstention when evidence is insufficient. Cancel, resume and restart controls retain their existing contracts. The activity log can be expanded and opens automatically for interrupted runs.

Starting a new investigation focuses and scrolls to the progress panel once. Reloading a saved investigation does not force scrolling. Ambient SVG animation pauses offscreen and when the browser tab is hidden; the existing pause control and reduced-motion setting apply throughout.

`/reviews/progress.html` is a development-only Vite entry for visual QA. It is clearly labelled as synthetic, imports the actual progress component, makes no API calls and supports manual stage changes. The production build includes only the normal `index.html` entry. Mocked browser tests verify real start/poll/report integration, stage inspection, failure recovery, mobile layout and motion controls without provider credits.

The problem statement's Track A brief informs the interactive research-angle section: growth versus asset quality, funding mix over time, and banking/co-lending/funding dependencies. These are starting questions, not claims that an investigation has established those findings. The preview uses an explicitly synthetic loan-book index and reminds visitors that loan growth alone cannot establish asset quality. The removed decorative cursor stays removed.
