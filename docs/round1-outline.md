# Round 1 outline

Track A uses one reusable pipeline: resolve a listed financial business, plan
questions from its profile, retrieve primary and independent public evidence,
normalize facts, calculate relationships deterministically, challenge the best
hypothesis, and publish only traceable claims. The interactive dashboard is
the official output; print and structured exports are supporting formats.

The system distinguishes bank, NBFC, insurer, exchange, asset manager and
diversified profiles, preserves reporting scope and fiscal periods, rejects
mirrored filings as independent, and abstains when the evidence gate fails.
